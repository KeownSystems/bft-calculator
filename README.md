# Board-Foot Calculator

A small React tool I built for a lumber shipping office. Pullers needed a consistent way to report rough-lumber quantities; an incorrect calculation could mean billing a customer for a very different amount than was shipped.

The form takes board length in feet, width in inches, thickness in quarter-inch units, and the number of layers. It calculates board feet and displays a second total using the selected board-code adjustment.

## Run locally

Install dependencies with `npm install`, then start the app with `npm start`.

This repository preserves the original tool and the operational problem it was built to solve.
